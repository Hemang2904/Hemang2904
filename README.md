I lead engineering at **[JewelBench AI](https://www.jewelbench.ai)**, a production platform that turns jewellery photographs and written briefs into manufacturable designs, costed bills of materials and 3D assets for manufacturers and retailers. I own the AI systems, the services they run in and the AWS deployment behind them. MSc Machine Learning, Royal Holloway, University of London.

<br>

<h2 align="center">What I build</h2>

<table>
<tr>
<td width="33%" valign="top">

### 💎 Forge, costing engine

Two to five reference photographs in; a costed bill of materials and a dimensioned spec sheet out. Vision-based analysis with self-consistency sampling and outlier-robust aggregation, paired with a deterministic dimension-based weight estimator.

**Measured against manufacturer ground truth:** about **10% median error** from printed dimensions plus finger size (**106 records, cross-validated**); about **15%** from a photograph alone (**110 records**).

**In production and billing since September 2026.**

</td>
<td width="33%" valign="top">

### 🎨 Design co-pilot

Rebuilt and shipped to every account in September 2026. Targeted image edits, a four-mode design wizard (variant creation, category transfer, sketch recreation, describe the change) capped at ten questions with a create-now option at every step, an automatic fidelity check with one retry, trade vocabulary including Indian terms, and **5,000-character briefs**.

The **Bulk Generator** plans and renders variations on the same engine.

</td>
<td width="33%" valign="top">

### 🛡️ Evaluation and production

Ground-truth datasets mined from a manufacturer's CAD archive, an A/B accuracy harness that gates releases, and regression suites that lock behaviour in. Audited our own accuracy claims and replaced the three that did not hold with measured figures.

Three services on AWS ECS (Java WebFlux API, Python 3D and estimator services), a React front end on CloudFront, rollback revisions, a security review with a risk register, authenticated service callbacks, and incident response.

</td>
</tr>
</table>

<h2 align="center">How I work</h2>

I designed the engineering workflow around coding agents for implementation under my review, an independent automated review before merge, and guard hooks that block secrets from sessions. The tooling I built for it is open source:

| Repo | What it does |
|---|---|
| [**secret-guard**](https://github.com/Hemang2904/secret-guard) | Prompt and tool-call guard hooks that stop secrets leaking into AI coding sessions |
| [**ai-worktree**](https://github.com/Hemang2904/ai-worktree) | Run coding agents in isolated git worktrees with reviewable merge-back |
| [**cockpit**](https://github.com/Hemang2904/cockpit) | A live terminal dashboard: roster, token burn, active agents and machine gauges |
| [**hook-pack**](https://github.com/Hemang2904/hook-pack) | A curated, individually selectable collection of production-quality agent hooks |
| [**ai-handoff**](https://github.com/Hemang2904/ai-handoff) | Hand a task between coding agents without losing context |
| [**notify-done**](https://github.com/Hemang2904/notify-done) | Desktop, phone and bell notifications when an agent run finishes or needs input |
| [**aispend**](https://github.com/Hemang2904/aispend) | One per-day, per-tool token and cost table from local agent logs |

Jewellery tools: [**gia-charts-carat-calc**](https://github.com/Hemang2904/gia-charts-carat-calc), a live carat-weight calculator with the GIA estimation formulas, and [**stl-weight-calculator**](https://github.com/Hemang2904/stl-weight-calculator), STL weight for precious metals with an interactive 3D viewer.
